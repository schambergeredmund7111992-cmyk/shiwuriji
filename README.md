# 拾物日记 · Little Things

全站文字使用用户提供的江城圆体 200W，转换为 WOFF 后保留全部 24,546 个字符及原始字形；页面、按钮、表单、日期数字与导出海报使用同一字体。字体文件位于 dist/assets/fonts，样式位于 dist/typography.css，不再请求 Google Fonts。

校园背景：使用用户提供的 9 张原始校园照片，默认第 9 张。所有照片共用 SVG 折射、模糊、颗粒和半透明磨砂层，在“我的 → 我的手账工具 → 更换背景”中预览并应用。取消选择会还原原背景；选择独立存于当前浏览器，不修改物品记录。第 10 张仅为效果参考，未作为素材使用。

参照 DayDayCup 的纸张、拍立得、标签小票、日历及悬浮导航形式，面向各种生活物品的独立网页版。

## 本地运行

在本目录执行 `python -m http.server 4173 --directory dist`，打开 http://localhost:4173。

## 功能

- 新增、编辑、删除物品记录；上传并压缩照片。
- 饮品、美食、阅读、数码、生活、其他六类；自定义标签、日期、可选金额、心情和备注。
- 月份、分类、关键词、收藏筛选与排序。
- 标签小票、备忘视图、照片日历、当天记录及月统计。
- 本地浏览器持久化；JSON 导入合并与导出；月度 PNG 海报。
- 示例数据显式标注，可单独移除；编辑示例后转为自己的记录。

没有服务器账号、云同步或 OCR。记录仅保存在当前浏览器 localStorage 中，建议导出备份。备份包含原照片、透明贴纸与备注，需妥善保管。

## 透明贴纸与自定义心情

- 使用 U²-NetP 轻量模型（ONNX Runtime Web），在 Web Worker 内完成本机抠图。模型与运行时随网站部署，不上传照片。
- 裁切透明边界，对 alpha 轮廓做白色外扩，输出真正带透明通道的 PNG。记录卡、标签小票顶部、日历与月度海报使用同一贴纸。
- 原照片单独保留。旧版记录自动补做贴纸；支持重新抠图、单独下载 PNG 贴纸；抠图失败保留原始记录并提供重试。
- 心情包含预设和最长 20 字的自定义值；编辑、刷新及备份导入后保留。
- 首次使用需要加载约 5 MB 模型及约 12 MB 运行时资源。复杂背景、透明玻璃、反光和主体重叠时分割可能不完整，建议使用主体清晰的照片。

## 开发与模型资源

安装依赖后运行 `npm run build`。模型随网站提供，文件为 dist/model/u2netp.onnx；可选运行 `python scripts/fetch-model.py` 将经过校验的资源保存到 outputs/model-cache，供本地离线调试。`dist/vendor` 为生成的运行产物。已发布网站通过“我的”提供源码归档下载。

本项目以 AGPL-3.0 分发，参见 LICENSE.md。背景分割库来源：https://github.com/imgly/background-removal-js ，ONNX Runtime 采用 MIT 许可。模型资源来自 IMG.LY 官方数据包；下载脚本逐块校验 SHA-256。

## 示例素材

图片源自 Unsplash 图片 CDN，仅为示例物品；不代表任何用户的真实记录。详见 download_assets.py 中的图片标识。品牌、图标和网站界面为独立实现，没有复制小程序的 Logo、源码或用户数据。可选 Google Fonts 样式请求不会包含用户记录。

## 部署

### Cloudflare Pages

`wrangler.jsonc` 指定静态输出目录 dist。首次部署运行 `npx wrangler login` 完成浏览器授权，然后运行 `npx wrangler pages project create shiwuriji --production-branch main` 和 `npx wrangler pages deploy dist --project-name shiwuriji --branch main`。后续更新只需再次部署 dist。

如果在 Cloudflare 控制台连接 GitHub 仓库，构建命令留空，输出目录填写 dist；所有静态产物已提交。直接上传与 Git 集成是不同的项目创建方式，请按实际采用的方式维护部署。

### Vercel（可选）

静态内容位于 dist/，Vercel 配置位于 vercel.json。导入 GitHub 仓库时使用仓库根目录，Framework Preset 选择 Other，Output Directory 为 dist。已提交完整静态产物，无需安装依赖或运行构建即可部署。

修改需要重新打包的源码后，在本地运行 `npm ci` 和 `npm run build`，提交更新后的 dist/。连接 Vercel GitHub 集成后，推送 main 分支即可触发更新。用户记录仍只保存在各自浏览器中。

模型源自 rembg 官方发布的 U²-NetP，MD5: 8e83ca70e441ab06c318d82300c84806。
# SMBU 校园示例与日历动效

## 奶蛙转身开场

每次完整打开页面时先显示透明背身奶蛙，停留 850ms 后用 580ms 的两面翻转效果切到正面，正面停留后淡出，约 2.6 秒进入当前网站页面。原照片的夜景、栏杆和白底均已去掉。开场独立于日记数据，不影响原有记录。

支持“跳过”和 Escape，遵从系统减少动态效果偏好。图片失败或超过 6 秒仍未就绪时自动关闭开场；正常结束和跳过都恢复原有交互状态。单页内切换记录、标签、日历、我的不重复播放。`node scripts/check-opening.mjs` 验证自动进入、跳过、图片失败、超时和减少动态效果。

## 展示方式与校园标识

贴纸库新增“咕咕嘎嘎”和“高雅企鹅”，每类 12 张，连同原有莫莫熊、奶系伙伴，共四类 56 张。新增贴纸去掉了用户截图中的手机界面、背景与说明文字，保留角色及相关配件，并以透明 WebP 提供。分类按钮在窄屏自动换行，编辑、保存、备份和重新打开记录均保留所选分类与贴纸。

新增或编辑记录时可选择“我的实物 / 贴纸”。贴纸库含 16 张莫莫熊及 16 张奶系伙伴，选择按记录保存。支持只用贴纸创建记录；从已有实物切到贴纸时仍保存原照片和实物抠图，切回无需重新上传。备份导入导出包含展示方式和贴纸编号，并验证白名单编号；旧备份默认展示实物。

页头右侧为莫莫熊及学校十周年标识。莫莫熊底部校名为“深圳北理莫斯科大学”。移除了用户标出的旧“拾”图标、页头宣传语、首页英文眉题和标题下说明。素材制作说明见 `ASSETS.md`。

内置示例为 2026 年 11 月 18–22 日的深北莫校园记录：学生代表证件、湖滨食堂午饭、十周年蛋糕、校史馆机器人及科学知识文化节“圣诞树”棉花糖。原图来自用户提供的校园照片，白边贴纸使用应用同一套本地抠图流程预生成。棉花糖及证件先定位主体区域再抠图；原始照片仍完整保留供详情查看。除明确提供的棉花糖 25 元外，其余金额留空。

升级时仅替换仍标记为 `demo` 的旧示例，保留用户自己的记录；若已移除全部示例，则不会再次添加。`node scripts/check-smbu.mjs` 验证首次记录、备份校验及升级时的数据保留行为。

日历贴纸在进入页面或切换月份后，滚动到可见区域时放大约 10% 再恢复；切换日期不重复播放，系统开启减少动态效果时停用动画。背景 03、04 标注图书馆，06、09 标注主楼。
