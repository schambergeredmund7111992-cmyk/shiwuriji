## 用 Trae 做出来的

这个项目的主体，是我在 Trae 的 Builder 里，一边描述想要的样子，一边让它生成、再一边改出来的。

先讲清楚这本手账应该长什么样、有哪几个页面、记录一件小事要走哪几步，让 Builder 给出第一版；然后按功能一块一块磨：照片怎么变成带白边的贴纸、标签小票怎么排、日历上的贴纸什么时候出现、月度海报能不能直接存进相册。哪里不对，就回到对话里继续改。

Trae 负责把想法快速变成能跑的页面；留下什么、删掉什么，由我来定。对一本手账来说，后者大概更重要——它最后要装的是自己的生活。

## 它能帮你留下什么

- **记录一件小事**：名称、日期、分类、金额、心情、标签和一段文字；上传照片时会自动压缩。
- **照片变成白边贴纸**：U²-NetP 模型在浏览器里本地抠图，不上传照片；同一张贴纸会出现在记录卡、标签小票、照片日历和月度海报上。
- **几种看生活的方式**：照片墙、标签小票、文字备忘、照片日历，还有每月的数量与小结。
- **做一张月度海报**：把这一个月的记录排成 PNG，存进相册或发给朋友。
- **数据能带走**：记录可以编辑、收藏、删除；支持 JSON 导出与导入合并。
- **只属于你**：没有账号，没有云同步，记录只留在这台设备的浏览器里。

## 一些小心思

- 每次打开，先看到一只背身的奶蛙，850 毫秒后开始翻身，用 580 毫秒转到正面，再淡出进入手账。可以跳过，也会遵循系统的“减少动态效果”设置。
- 九张校园背景都可以换。03、04 是图书馆，06、09 是主楼。
- 贴纸库有 56 张：莫莫熊、奶系伙伴、咕咕嘎嘎、高雅企鹅各一组；也可以只用贴纸记一条，不传照片。
- 全站用江城圆体 200W，页面、按钮、日期数字和导出的海报是同一套字。

## 照片和隐私

抠图用的是 U²-NetP 轻量模型，模型和 ONNX Runtime Web 都随网站一起提供，推理在 Web Worker 里完成，照片不会离开这台设备。第一次做贴纸需要加载约 5 MB 模型和约 12 MB 运行时；遇到玻璃、反光或主体重叠，抠图可能不太完整，换一张主体清楚的照片通常会好很多。

记录保存在浏览器的 localStorage 里。换设备、换浏览器或清理浏览器数据都可能丢失；如果这些记录对你很重要，记得在“我的”里导出备份。

## 本地运行

```bash
python -m http.server 4173 --directory dist
```

打开 <http://localhost:4173> 。`dist/` 是完整的静态产物，可以直接部署，不需要先安装依赖。

如果要改源码：

```bash
npm ci
npm run build
```

## 部署

目前部署在 Cloudflare Pages：<https://shiwuriji.pages.dev/> 。

```bash
npx wrangler pages deploy dist --project-name shiwuriji --branch main
```

仓库也保留了 `vercel.json`，输出目录同样指向 `dist/`。
